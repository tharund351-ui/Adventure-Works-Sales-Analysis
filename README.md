# Adventure Works Sales Analysis

## Project Overview
End-to-end sales analytics project using Excel, Power BI, Tableau Public, and MySQL to analyze sales performance, profitability, customer behavior, product trends, and regional sales.

## Project Objectives
- Analyze total sales, production cost, profit, and profit margin.
- Identify top-performing products and customers.
- Compare sales performance across regions.
- Analyze year-wise, quarter-wise, and month-wise sales trends.
- Build interactive dashboards for business insights.

## Tools and Technologies
- **Microsoft Excel:** Data cleaning, formulas, PivotTables, and PivotCharts.
- **Power Query:** Data transformation and combining sales tables.
- **Power BI:** Interactive dashboards, data modeling, and DAX measures.
- **Tableau Public:** Visualizations, dashboards, and interactive filters.
- **MySQL:** SQL queries, joins, and aggregations.

## Project Components
1. **Excel Analysis** — Data preparation, calculations, and PivotTables.
2. **Power BI Dashboard** — Sales Overview and Performance Analysis.
3. **Tableau Dashboard** — Interactive sales analysis and regional comparisons.
4. **SQL Analysis** — Business questions and sales data analysis.

## Key Business Questions
- What is the overall sales performance?
- Which products and customers generate the most sales?
- Which regions perform best?
- How do sales and profits change over time?
- How do production costs affect profitability?
